# Power BI Salary Insights Dashboard

## Project Overview

In this project, I developed an interactive Power BI dashboard to analyze survey data from data professionals. The goal was to uncover insights related to salaries, job roles, tools used, experience levels, and geographic distribution.

The dashboard was designed to transform raw survey data into clear, decision oriented visual insights using dynamic filters and interactive visuals.

---

## Dataset

The dataset consists of survey responses from data professionals and includes:

- Job title
- Salary
- Country
- Programming language preference
- Industry
- Experience level
- Work satisfaction indicators

The data required transformation and modeling before visualization.

---

## Tools Used

- Power BI
- Power Query for data transformation
- DAX for calculated measures
- Data modeling
- Interactive visualizations and slicers

---

## Project Workflow

### 1. Data Cleaning and Transformation

- Cleaned and structured the dataset using Power Query
- Handled missing values and standardized categorical fields
- Created calculated columns where necessary

### 2. Data Modeling

- Built relationships between tables where applicable
- Created calculated measures using DAX
- Structured the model to support dynamic filtering

### 3. Dashboard Development

- Designed interactive visuals including bar charts, KPI cards, and distribution charts
- Implemented slicers for role, country, and experience filtering
- Built salary comparison visuals across different segments

---

## Key Insights Delivered

- Salary trends across different job roles
- Country level salary comparisons
- Tool preferences among professionals
- Experience level impact on compensation
- Satisfaction patterns across roles

---

## Outcome

The final dashboard provides an interactive, user friendly interface that allows stakeholders to explore trends and compare key metrics dynamically. This project demonstrates practical skills in data transformation, modeling, DAX calculations, and business focused dashboard design using Power BI.
